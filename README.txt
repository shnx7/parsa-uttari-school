# उच्च माध्यमिक विद्यालय, परसा जटौरी — Free Website

This is a static website that can be hosted for free on GitHub Pages, Netlify, or Cloudflare Pages.

## Files
- index.html — website content
- style.css — design and responsive layout
- script.js — mobile menu + year
- assets/school-staff.jpg — image supplied for the staff section

## Important
The supplied image contains individual staff mobile numbers. The website intentionally displays the image only as provided, but the numbers should not be published publicly unless the school has permission from the concerned staff members. For the final public version, replace the image with a staff gallery/table that omits private phone numbers.
